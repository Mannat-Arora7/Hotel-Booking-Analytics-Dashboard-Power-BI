# Hotel-Booking-Dashboard-Power-BI
# 🏨 Hotel Booking Demand Analysis Dashboard | Power BI

## Project Overview

The Hotel Booking Demand Analysis Dashboard is an interactive Business Intelligence solution developed using Microsoft Power BI. The project analyses hotel booking data to uncover trends in reservations, cancellations, customer behaviour, occupancy, and revenue-related metrics. The dashboard enables stakeholders to make data-driven decisions through dynamic visualizations and key performance indicators (KPIs).

---

## Objectives

- Analyse hotel booking patterns and customer behaviour.
- Monitor booking and cancellation trends.
- Compare City Hotel and Resort Hotel performance.
- Identify factors influencing booking demand.
- Create an interactive dashboard for business decision-making.

---

## Tools & Technologies

- Microsoft Power BI
- Power Query

- Data Modeling

## Dashboard Features

- Executive Overview Dashboard

## Key KPIs

- Total Bookings
- Booking Cancellation Rate
- Average Daily Rate (ADR)
- Average Length of Stay

- Hotel-wise Booking Performance

## Data Preparation

- Cleaned and transformed raw data using Power Query.
- Handled missing values and inconsistent records.
- Converted data types and created calculated columns.
- Built DAX measures for business KPIs.
- Optimized the data model for better dashboard performance.

## Business Insights

- Identified peak booking seasons and customer demand patterns.
- Analysed cancellation behaviour across customer segments.
- Compared booking performance between City Hotels and Resort Hotels.
- Evaluated ADR trends and occupancy-related metrics.
- Delivered actionable insights to support business decisions.
